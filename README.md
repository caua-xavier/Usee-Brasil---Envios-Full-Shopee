# Usee-Brasil---Envios-Full-Shopee
Gestor de Envios Full Shopee da Usee Brasil — aplicação single-file HTML que unifica envios Full para Shopee Moda e Sports: catálogo, FBS, NF-e, Pedido Cross, conferência de envio, gráfico Enviado × Vendido no Full e extensão Chrome com overlay na Shopee Seller Center. Funciona offline, sem backend, com auto-atualização.
